# Portfolio Website - Abdalrhman

## 🔥 Overview

A personal portfolio website to showcase my work, experience, and contact details.  
The website is designed with a modern and elegant style inspired by Apple's latest UI aesthetics.

## 🎨 Design & Layout

### 🧭 Navbar

- The **Navbar** covers **80% of the page width**.
- Has **rounded borders** on both sides shaped like **half circles**.
- Contains **4 main links**:
  - Home
  - Projects
  - Experience
  - Contact
- On the **left side (outside the navbar)**: Display the name **"Abdalrhman"**.
- On the **right side (outside the navbar)**: A **Theme Toggle Icon** (for light/dark mode).

### 🌊 Navbar Hover Effect

- Each link in the navbar has a **hover effect** similar to Apple's new UI.
- On hover → a **transparent water-drop splash effect** appears behind the link.
- This creates a soft, glassy, modern interaction.

## ⚙️ Features

- Responsive design (mobile/tablet/desktop).
- Smooth animations & transitions.
- Theme toggle (light/dark).
- Glassmorphism & water-drop hover effects.
- **Enhanced UI with PrimeNG components** for a more professional appearance.

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS (SCSS), TypeScript, Angular 19.
- **UI Components:** PrimeNG 19.1.4 for professional UI elements.
- **Icons:** PrimeIcons 7.0.0 for comprehensive icon set.
- **Effects:** CSS animations, custom hover effects.

## 🎨 PrimeNG Enhancements

This portfolio has been enhanced with PrimeNG components to provide a more professional and polished appearance:

- **Buttons:** Enhanced with icons and consistent styling
- **Cards:** Used for project displays and content sections
- **Chips:** Technology tags in the projects section
- **Form Elements:** Improved input fields with floating labels
- **Timeline:** Professional experience visualization
- **Icons:** Visual cues throughout the portfolio

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

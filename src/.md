# Portfolio Website - Abdalrhman

## 🔥 Overview
A personal portfolio website to showcase my work, experience, and contact details.  
The website is designed with a modern and elegant style inspired by Apple's latest UI aesthetics.

---

## 🎨 Design & Layout

### 🧭 Navbar
- The **Navbar** covers **80% of the page width**.
- Has **rounded borders** on both sides shaped like **half circles**.
- Contains **4 main links**:
  - Home
  - Projects
  - Experience
  - Contact
- On the **left side (outside the navbar)**: Display the name **"Abdalrhman"**.
- On the **right side (outside the navbar)**: A **Theme Toggle Icon** (for light/dark mode).

### 🌊 Navbar Hover Effect
- Each link in the navbar has a **hover effect** similar to Apple’s new UI.
- On hover → a **transparent water-drop splash effect** appears behind the link.
- This creates a soft, glassy, modern interaction.
